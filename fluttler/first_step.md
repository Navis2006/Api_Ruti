# Documentación de API Backend para App Móvil (Flutter)

Este documento especifica los endpoints, estructuras de datos y flujos necesarios para integrar la App Móvil (Flutter/Dart) con el Backend existente (PHP/MySQL) de  **RutiTruck** .

---

## 1. Configuración General

* **Protocolo** : HTTPS
* **Formato de Intercambio** : JSON (`Content-Type: application/json`)
* **Autenticación** : Token (JWT o Session ID) enviado en Headers.
* **Base URL** : `https://tu-dominio.com/api` (Ruta sugerida para los nuevos scripts PHP).

---

## 5. Mapeo Pantallas vs Endpoints

| Pantalla App Móvil           | Endpoint Principal                   | Acción                              |
| ----------------------------- | ------------------------------------ | ------------------------------------ |
| **1. Login**            | `POST /api/login_mobile.php`       | Autenticar y guardar Token.          |
| **2. Registro**         | `POST /api/register_operator.php`  | (Opcional) Crear cuenta operador.    |
| **3. Mis Viajes**       | `GET /api/trips.php`               | Listar tarjetas de viajes.           |
| **4. Viaje Activo**     | `GET /api/trip_details.php`        | Mostrar mapa con polilínea de ruta. |
| **-- Botón Finalizar** | `POST /api/update_trip_status.php` | Cambiar estado a 'Finalizado'.       |
| **5. Reportar Falla**   | `POST /api/report_alert.php`       | Enviar alerta con geolocalización.  |
| **6. Perfil**           | `GET /api/profile.php`             | Ver datos del operador.              |

## 6. Recomendaciones Técnicas para Backend Dev

1. **Parseo de Geometry** : La tabla `rutas` usa el tipo de dato `geometry`. En PHP necesitarás usar `ST_AsText(trazado_geom)` en tu consulta SQL y luego procesar ese string (WKT) para convertirlo en el array JSON `[ {lat, lng}, ... ]` que espera Flutter.
2. **Imágenes** : Si los vehículos o usuarios tienen fotos, asegura que la API devuelva la URL pública completa (ej: `https://.../uploads/foto.jpg`) y no solo el path relativo.
3. **Seguridad** : Valida siempre que el usuario que intenta ver/modificar un viaje sea realmente el asignado (`operador_usuario_id`).
